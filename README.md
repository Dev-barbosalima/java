# Java

## Esse projeto tem como objetivo, firmar conhecimentos em java.

- Soma: O usuário interage via console com o programa, onde o mesmo
deve inserir 2 números inteiros. O programa ira á realizar a soma desses
dois número e apresentar o resultado da soma para o usuário

_Programa elaborado em Java 21_

_Lembresse de ter, no minimo, o JDK 21 instalado em sua máquina_

[Guia para instalar o JDK 21 aqui.](https://www.oracle.com/br/java/technologies/downloads/#java21)

### IDEs.

- Caso utilize Vscode, instale a extensão Pack for Java (ID da extensão: vscjava.vscode-java-pack)
fornecido pela própria Microsoft.
- Se optar por utilizar Intellij, aponte a JDK instalada no passo anterior nas configurações do
editor.
